# 삽입 정렬 vs 쉘 정렬 비교 횟수 분석

- 코드: `sort_compare.c` (`gcc -O2 -o sort_compare sort_compare.c && ./sort_compare`)
- 데이터: `srand(12345)` 기반 무작위 정수, 크기별 원본 1개를 복사해 세 알고리즘에 동일 적용
- 비교 횟수: 데이터 값 간 비교만 1회로 계산 (반복문 조건 제외). 모든 결과 오름차순 검증 완료.

## 1. 데이터 크기 증가에 따른 변화
- 삽입 정렬은 n이 2배가 될 때마다 비교 횟수가 약 4배(248,805 → 1,013,216 → 4,007,959 → 15,951,095 → 63,620,807)가 된다. 무작위 데이터의 평균 비교 횟수가 약 n²/4이기 때문이다. n=1,000에서 n²/4 = 250,000으로 측정값과 거의 일치한다.
- 쉘 정렬은 2배 증가 시 약 2.2~2.5배(기본: 14,627 → 36,491 → 84,033 …)만 증가한다. O(n²)보다 훨씬 완만하며 n log n에 가까운 증가 양상이다.

## 2. 삽입 정렬과 쉘 정렬의 성능 차이
- n=1,000에서 약 17배였던 차이가 n=20,000에서는 약 160~175배로 벌어진다. 데이터가 커질수록 쉘 정렬의 이점이 급격히 커진다.
- 원인: 삽입 정렬은 원소를 한 칸씩만 이동시키므로, 멀리 떨어진 원소를 제자리로 보내려면 이동 거리만큼 비교가 필요하다(역순쌍 수 ≈ n²/4 만큼 비교). 쉘 정렬은 큰 간격에서 원소를 한 번에 멀리 이동시켜 역순쌍을 먼저 대량 제거하고, 마지막 h=1 단계에서는 이미 거의 정렬된 배열을 처리한다. 삽입 정렬은 거의 정렬된 입력에서 O(n)에 가깝게 동작하므로 마지막 단계의 비용이 매우 작다.

## 3. 기본 간격 vs Knuth 수열
- 모든 크기에서 Knuth가 기본 간격보다 적은 비교 횟수를 보였다 (n=1,000: 약 7.7%, n=2,000: 12.0%, n=4,000: 7.8%, n=8,000: 10.9%, n=16,000: 13.5%, n=20,000: 8.0% 감소).
- 절대 차이는 작지만 일관된 우위이다. 이 실험은 크기당 1회 측정이라 감소율이 들쭉날쭉(8~13%)한 점은 무작위 데이터 편차의 영향으로 볼 수 있다.
- 특히 n=16,000(2의 거듭제곱에 가까운 크기)에서 기본 간격의 비교 횟수가 n=20,000과 비교해 상대적으로 크다(16,000에서 507,889, 20,000에서 621,816으로 n이 1.25배인데 횟수는 1.22배 증가). 기본 간격이 2의 거듭제곱 구조에 약하다는 점은 아래에서 설명한다.

## 4. 간격 수열이 성능에 영향을 주는 이유
- **기본 간격(n/2, n/4, ...)**: n이 2의 거듭제곱 계열이면 모든 간격이 짝수(마지막 1 제외)이다. 짝수 간격에서는 짝수 위치 원소와 홀수 위치 원소가 서로 섞이지 않고 따로 정렬되다가, h=1 단계에서야 처음 합쳐진다. 즉 앞 단계의 정렬 효과가 서로 다른 부분열에 전달되지 않아 마지막 단계에 남는 역순쌍이 많아진다. 이론적으로 최악의 경우 O(n²)까지 갈 수 있다.
- **Knuth 수열(1, 4, 13, 40, ...)**: 간격이 약 3배씩 줄고 서로 배수 관계가 아니어서(서로소에 가까움) 각 단계가 앞 단계와 다른 원소 조합을 섞는다. 그 결과 h=1 직전의 배열이 더 정렬된 상태가 되어 마지막 단계의 비교가 줄어든다. 알려진 시간 복잡도는 O(n^1.5)로, 기본 간격의 최악 O(n²)보다 낫다.
- 또한 Knuth는 단계 수가 적다(n=20,000에서 8단계: 6,561 … 1, 기본은 14단계). 단계마다 최소 n-h번의 비교가 필요하므로 단계 수 감소도 비교 횟수를 줄인다. 다만 무작위 데이터에서는 기본 간격도 평균적으로 꽤 잘 동작해서 차이가 10% 내외에 그친 것이다.

## 결론
쉘 정렬은 간격을 이용해 멀리 떨어진 원소를 먼저 정리함으로써 삽입 정렬의 O(n²) 비교를 크게 줄이며, n이 클수록 이득이 커진다. 간격 수열은 단계 간 상호작용과 단계 수를 결정하므로, 서로 배수가 되지 않는 Knuth 수열이 기본 간격보다 일관되게 적은 비교 횟수를 보였다.
